# 국내 총판 사전 — 시드 초안

> ## ⛔ 폐기 (ADR-0022, 2026-09-23)
>
> 국내 유통 매칭(§5.7.1)과 `importers` 테이블을 폐기했다. 이 사전을 쓸 곳이 없다.
> 기록으로만 남긴다.

`pc-builder-spec.md` §5.7.1 **5단계(총판 식별)** 에서 쓸 사전의 시드다.
이슈 #4에 해당한다.

- 관련 ADR: ADR-0003 (parts/skus 분리 — `importers` 테이블)
- 선행: 없음 (조사와 병렬 진행 가능)

> ## ⚠️ 이 문서는 **미검증 초안**이다
>
> handoff-guide §4가 정의한 이슈 #4의 방법은 "네이버 쇼핑에서 부품을 검색해 총판명
> 접미사를 모으는" 것이다. **이 세션에는 네이버 쇼핑 API 접근 권한이 없어 그 수집을
> 수행하지 못했다.** (앱 등록은 handoff-guide §7에서 사용자가 직접 하는 작업으로
> 분류되어 있다.)
>
> 따라서 아래 목록은 실제 상품명에서 수집한 것이 **아니라** 사전 지식으로 작성한
> 시드이며, **표기 형태가 실제 상품명과 다를 수 있다.** 그대로 코드에 넣지 말고
> §4의 검증 절차를 거친다. 검증 전 상태를 `confidence` 필드로 구분해 저장한다.
>
> 웹 검색으로 보강을 시도했으나 자료가 커뮤니티 게시물 위주로 신뢰도가 낮고
> 일부 출처는 네트워크 정책상 접근이 차단되어, **근거 없는 항목을 채우기보다
> 비워 두는 쪽을 택했다** (CLAUDE.md: 근거 없는 수치를 지어내지 않는다).

## 1. 왜 사전으로 푸는가

국내 PC 부품 상품명에는 총판명이 거의 항상 **접미사**로 붙는다.

```
"ASUS TUF GAMING B650-PLUS WIFI 대원CTS"        → 대원CTS
"GIGABYTE B760M 어로스 엘리트 피씨디렉트"        → 피씨디렉트
"MSI 지포스 RTX 4070 SUPER 벤투스 ... 이엠텍"    → 이엠텍
```

스펙 §5.7.1의 판단대로 **ML이 필요 없다.** 접미사 사전 매칭으로 대부분 잡히고,
미매칭은 검토 큐로 보내 사전을 늘리면 된다. 사전이 커질수록 정확도가 올라가는
단조 구조라 초기 불완전성이 치명적이지 않다.

---

## 2. 데이터 구조

`pc-builder-spec.md` §5.8의 `importers` 테이블에 대응한다.

```
importers (id, name, aliases_json, support_url, note)
```

| 필드 | 내용 |
|---|---|
| `name` | 정규 총판명 (표시용 대표 표기) |
| `aliases_json` | **매칭에 쓰는 표기 변형 전부.** 띄어쓰기·영문·약어 포함 |
| `support_url` | A/S 안내 페이지. 보증 정책(§5.8 `warranty_policies`)의 근거 |
| `note` | 주의사항. 특히 AIB 겸업 여부 |

추가로 **검증 상태를 함께 둔다.**

```
confidence : seed | verified      seed = 이 문서에서 온 미검증 항목
source_url : 검증 근거            verified 로 승격할 때 필수
verified_at: 검증 시각
```

§5.5의 "모든 필드에 source_url과 verified_at" 원칙을 총판 사전에도 그대로 적용한다.

## 3. 시드 목록

**`confidence: seed`로 적재할 후보다.** 표기 정확도는 검증 전까지 보장되지 않는다.

### 3.1 총판명 — 상대적으로 확신이 있는 것

국내 PC 부품 유통에서 오래 쓰인 이름들이다. **이름 자체**는 신뢰도가 높지만,
상품명에 붙는 **정확한 표기 형태**(띄어쓰기, 접미사 위치)는 검증이 필요하다.

| 총판명 | 표기 변형 후보 | 주 취급 (검증 필요) |
|---|---|---|
| 대원CTS | 대원씨티에스, 대원 CTS, DAEWON | 메인보드·그래픽카드 |
| 피씨디렉트 | PC디렉트, 피시디렉트, PCDirect | 메인보드·그래픽카드 |
| 제이씨현시스템 | 제이씨현, JC현, JCHyun | 메인보드·그래픽카드 |
| 이엠텍 | emTek, 이엠텍아이엔씨 | 그래픽카드 ★ §3.3 주의 |
| 서린씨앤아이 | 서린, SeorinC&I | 그래픽카드·주변기기 |
| STCOM | 에스티컴, 에스티콤 | 메인보드·그래픽카드 |
| 디앤디컴 | D&D컴, 디앤디 | 메인보드 |
| 인텍앤컴퍼니 | 인텍앤컴, INTECH | 메인보드·그래픽카드 |
| 조텍코리아 | ZOTAC코리아, 조텍 | 그래픽카드 |
| 컴포인트 | COMPOINT | 그래픽카드 |
| 코잇 | COIT | 주변기기·부품 |
| 웨이코스 | WAYCOS | 파워·케이스 |
| 에센코어 | ESSENCORE, 클레브 | 메모리 |
| 리뷰안 | REVIEWAN | 스토리지 |
| 이노베이션티뮤 | 티뮤, TIMU | 주변기기 |

**"주 취급" 열은 특히 신뢰도가 낮다.** 총판-브랜드 관계는 계약이라 수시로 바뀌고,
한 총판이 여러 브랜드를, 한 브랜드가 여러 총판을 갖는 다대다다. 검증 전까지
**매칭 로직에 쓰지 않는다** — §4.3 참조.

### 3.2 이 목록에 없는 것을 처리하는 방법

시드가 완전할 수 없다는 전제로 설계한다.

- 접미사 매칭 실패 → **검토 큐로 보낸다.** 버리지 않는다
- 검토 큐에 같은 미지 토큰이 N회 이상 쌓이면 신규 총판 후보로 승격 제안
- 총판을 식별하지 못해도 **SKU는 생성한다.** `importers.id`를 NULL로 두면 된다
  (§5.8에서 `importer_id NULL` 허용). 유통 판정(§5.7.1 7단계)은 총판 식별과 무관하다

### 3.3 ★ AIB 겸업 총판 주의

스펙 §5.7.1이 명시한 함정이다.

> 주의: 이엠텍처럼 **AIB 브랜드이면서 총판인 경우**가 있다. 브랜드 필드와 혼동하지
> 않게 구분한다

`parts.brand`(글로벌 AIB 제조사)와 `skus.importer_id`(국내 수입사)는 **다른 축**이다.
같은 문자열이 양쪽에 등장할 수 있고, 그때 자동으로 같은 것으로 묶으면 안 된다.

```
parts.brand = "emTek"        ← OpenDB의 AIB 제조사
skus.importer = "이엠텍"      ← 국내 수입사

→ 우연히 같은 회사지만, 매칭 로직은 이를 별개 필드로 다뤄야 한다.
   "brand == importer 이면 하나로 합친다" 같은 규칙을 넣지 않는다.
```

겸업 후보로 확인이 필요한 곳: 이엠텍, 조텍코리아, 갤럭시(한국 지사).

## 4. 검증 절차 (이슈 #4의 실제 완료 조건)

**네이버 쇼핑 API 앱 등록 후** 수행한다 (handoff-guide §7의 사용자 작업).

```
1. 카테고리별 인기 부품 30~50개를 네이버 쇼핑에서 조회
2. 상품명 끝 1~2 토큰을 추출해 빈도순 집계
3. §3.1 시드와 대조
   ├ 일치        → confidence: verified, source_url 기록
   ├ 표기 차이    → aliases_json에 실제 표기 추가
   └ 시드에 없음  → 신규 총판 후보로 등록
4. 빈도 상위인데 총판이 아닌 토큰(용량·색상·사은품 등)은 부정 토큰 목록(§5)으로
5. 커버리지 측정 — 조회한 상품 중 총판 식별에 성공한 비율
```

**완료 기준 제안**: 카테고리별 인기 부품 상품명의 **80% 이상에서 총판을 식별**.
100%를 목표하지 않는다. 미식별은 `importer_id NULL`로 정상 처리되며, 검토 큐가
사전을 계속 키운다.

### 4.1 검증 없이 하지 말 것

- 총판명으로 **브랜드를 추론**하지 않는다 (§3.1 "주 취급"은 참고용)
- 시드 표기가 안 맞는다고 상품을 **버리지** 않는다. 검토 큐로 보낸다
- 접미사가 아닌 위치의 우연한 일치를 총판으로 잡지 않는다.
  **끝에서부터** 매칭한다

## 5. 부정 토큰 목록 (§5.7.1 4단계)

총판 사전과 함께 쓰이는 제외 키워드다. 이쪽은 상품명 관행이라 시드 신뢰도가 높다.

| 구분 | 토큰 |
|---|---|
| 상태 | 중고, 리퍼, 리퍼브, 재생, A급, B급, 미개봉, 개봉만 |
| 유통 형태 | 벌크, 병행수입, 해외직구, 직구, 수입, 정품아님 |
| 묶음 | 본체, 세트, 패키지, 조립PC, 완본체, 견적, 묶음 |
| 부속품 | 브라켓, 케이블, 커넥터, 어댑터, 받침대, 지지대, 홀더, 쿨러만 |
| 기타 | 렌탈, 대여, 예약, 사은품, 증정 |

**"정품"은 부정 토큰이 아니다.** 국내 상품명에 흔히 붙는 긍정 표기다.

**주의**: `쿨러만`, `브라켓` 같은 토큰은 해당 카테고리에서는 정상 상품일 수 있다.
부정 토큰은 **카테고리별로 다르게** 적용한다. 전역 목록 하나로 처리하지 않는다.
