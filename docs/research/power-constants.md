# 전력 계산 상수 조사 — 구간 판정으로 해결

규칙 7에 필요한 상수를 점 값으로 확정하려 했으나 **출처 기준을 만족하지 못했다.**
대신 §5의 구간 판정 제안이 승인되어 그렇게 구현했다 (`POWER_ASSUMPTIONS`).
**규칙 7의 판정 불가율이 100% → 0%가 됐다** (§8).

- 근거 문서: `pc-builder-spec.md` §4.1(규칙 7), `docs/compat-rules.md` §7.2
- 관련 ADR: ADR-0009(판정 불가), ADR-0004(단일 수치를 내놓지 않는다)

---

## 1. 왜 지금 이걸 했는가

`docs/research/opendb-schema-analysis.md` §9.3의 실측에서 **규칙 7이 무작위 300개
조합 전부(100%)에서 판정 불가**로 나왔다. 케이스 데이터 결측(85%)보다 영향 범위가
넓어 우선순위가 가장 높았다.

## 2. 필요한 것은 두 개다 (넷이 아니다)

`compat-rules.md` §7.2는 상수 네 개(메인보드·메모리·스토리지·팬)를 열거했지만,
**MVP 취급 부품이 6종(CPU·메인보드·메모리·GPU·케이스·파워)이라 스토리지와 팬은
견적에 들어오지 않는다** (`pc-builder-spec.md` §3). Phase 0b에서 실제로 필요한 것은

```
메인보드 소비전력
메모리 모듈당 소비전력
```

스토리지·쿨러 상수는 Phase 1에서 그 부품이 추가될 때 확정하면 된다.

## 3. 찾은 것

PSU 제조사 Seasonic이 자사 계산기 가이드에 부품별 범위를 공개하고 있다.
검색 결과가 그 페이지의 내용으로 제시한 값은 다음과 같다.

| 항목 | 범위 |
|---|---|
| 메인보드 | 25 ~ 80 W |
| 메모리 (모듈당) | 2 ~ 5 W (전체 구성 20W 이하) |
| 팬 (개당) | 1 ~ 3 W (조명 포함 시 6W) |
| AIO 수랭 | 15 ~ 30 W |
| 스토리지 | 최대 15 W |
| 권장 여유분 | 20 ~ 30% |

여유분 20~30%는 스펙 §4.1이 정한 배수 1.3과 일치한다. 이건 확인된 셈이다.

메모리는 Crucial(메모리 제조사)이 "모듈당 5W"를 경험 규칙으로 제시한다는 검색 결과도
있었다.

## 4. 왜 그래도 채우지 않았는가

두 가지가 겹친다.

**① 1차 출처를 직접 읽지 못했다.** 이 실행 환경의 네트워크 정책이 `seasonic.com`과
`crucial.com`을 차단한다 (`EGRESS_BLOCKED`). 검색 엔진 요약이 그 페이지의 수치라고
제시한 것을 본 것이고, 원문 문장을 확인하지 못했다. 사용자가 수십만 원을 쓰는 결정에
들어가는 숫자를 요약 인용만으로 넣지 않는다 (CLAUDE.md: 근거 없는 수치를 지어내지
않는다).

**② 범위가 넓어 점 값을 고르는 것 자체가 창작이다.** 메인보드 25~80W는 3배 차이다.
여기서 "50W" 같은 값을 고르면 그 숫자에는 근거가 없다. 규칙 7이 오류 등급이라
틀리면 사용자가 멀쩡한 파워를 못 쓴다고 판단하거나, 부족한 파워를 괜찮다고 믿는다.

SEO 성격 사이트들은 15~60W, 80~100W 같은 값을 내놓는데 서로 맞지 않고 출처도 없다.
Anandtech의 실측 리뷰는 접근이 되지 않았다.

## 5. 제안 — 점 값이 아니라 구간으로 판정한다

**이 프로젝트에는 이미 같은 문제를 푸는 원칙이 있다.** ADR-0004와 §6.6.4가 성능
예측에 대해 정한 것이다.

> 단일 수치를 내놓지 않는다. 예측 구간의 폭이 곧 신뢰도 표시다.
> 데이터 밀도가 낮은 영역에서 넓은 구간이 나오는 건 결함이 아니라 정직함이다.

전력에도 같은 원칙을 적용할 수 있다. 상수를 점 값이 아니라 **범위**로 두고 판정을
세 갈래로 낸다.

```
총 소비전력_최소 = CPU + GPU + 보드_최소 + 메모리_최소 × 모듈수
총 소비전력_최대 = CPU + GPU + 보드_최대 + 메모리_최대 × 모듈수

PSU 정격 >= 총_최대 × 1.3   → 통과   "여유 있음"
PSU 정격 <  총_최소         → 오류   "가정을 아무리 낮게 잡아도 부족"
그 사이                     → 경고   "가정에 따라 갈림. 넉넉한 쪽을 권함"
```

이러면 **범위 값만으로 오늘 바로 쓸 수 있다.** 점 값을 지어낼 필요가 없고, 결과
화면에 "보드 25~80W로 가정" 하고 출처를 그대로 노출할 수 있다 (§7.2가 요구하는 것).

경계 구간이 넓게 나오는 것은 결함이 아니라 데이터가 그만큼 없다는 정직한 표시다.

**다만 이건 스펙 §4.1의 판정식을 바꾸는 것이다.** `총 소비전력 × 1.3 ≤ PSU 정격`이라는
점 계산을 구간 계산으로 바꾸므로, CLAUDE.md 작업 규칙 2에 따라 **문서를 먼저 고치고
승인을 받아야 한다.** 승인 전까지 규칙 7은 판정 불가를 유지한다.

## 6. 대안

| 대안 | 평가 |
|---|---|
| 구간 판정 (§5 제안) | 범위 값만으로 오늘 동작. 프로젝트 기존 원칙과 일치 |
| 1차 출처를 직접 확인해 점 값 확정 | 이 환경에서 차단됨. 사용자가 직접 페이지를 열어 수치를 확인해주면 가능 |
| 직접 측정 | 벽면 전력계로 실측. 가장 확실하지만 조합 수가 많아 일반화가 어렵고, handoff-guide §7의 사용자 작업 성격 |
| 보수적 점 값 채택 (예: 보드 80W 상한) | 항상 과대 추정이라 "더 큰 파워를 사라"는 쪽으로 편향된다. 판단을 돕는 도구라는 목적에 어긋난다 |

## 8. 결과 — 구간 판정 채택 후

§5 제안이 승인되어 구현했다. 스펙 §4.1과 `docs/compat-rules.md` §7을 먼저 고치고
`packages/compat`에 반영했다.

```
PSU 정격 ≥ 총_최대 × 1.3   →  통과   여유 있음
총_최소 ≤ PSU < 그 값       →  경고   가정에 따라 갈림 (노랑)
PSU < 총_최소               →  오류   안 됨 (빨강)
```

**채택한 가정** (`POWER_ASSUMPTIONS`)

| 항목 | 범위 |
|---|---|
| 메인보드 | 25 ~ 80 W |
| 메모리 (모듈당) | 2 ~ 5 W |

출처는 Seasonic PSU 계산기 가이드로 표기하되 **`verified: false`로 두어 "원문 미확인"을
결과에 그대로 노출한다.** 숨기면 사용자가 검증된 수치로 오해한다.

**실측 변화** (무작위 300개 조합, `npm run sample -w @buildfit/ingest`)

| | 이전 | 이후 |
|---|---|---|
| 규칙 7 판정 불가 | **100%** | **0%** (통과 257 / 실패 43) |
| 판정 불가가 있는 견적 | 100% | **86.7%** |

국내 인기 구성(9800X3D · B650 TOMAHAWK · RTX 5080 · RM850x)은 **통과 7 · 실패 1 ·
판정 불가 0**이 됐다. 남은 실패 1건은 규칙 8이고, 매칭된 PSU가 2018년형 RM850x라
12VHPWR이 없는 실제 비호환이다.

남은 판정 불가 86.7%는 규칙 6(케이스 데이터 83.3%)과 규칙 8의 모순 검사(20.7%)가
만든다. **이제 케이스 보강이 가장 큰 개선 항목이다.**

## 7. 원문 확인 — 2026-09-24 (이슈 #5)

`seasonic.com`은 여전히 이 환경에서 Cloudflare 403이다. **웹 아카이브의 2025-07-11 사본**을
읽었다: <https://web.archive.org/web/20250711215224/https://seasonic.com/insights/psu-calculator-using-guide-2025/>
(원 페이지 게시 2025-06-13, 수정 2025-06-13).

§3의 요약 인용이 원문과 일치한다.

| 항목 | 원문 |
|---|---|
| 메인보드 | "Consumes roughly 25 to 80 watts. It all depends on its type, chipset, and additional features altogether." |
| 메모리 | "Draws about 2 to 5 watts per module. A full setup usually uses no more than 20 watts in total." |
| 스토리지 | "They are generally quite efficient, so you can put up to 15W, especially for some HDDs." |
| 팬 | "Conventional fans consume 1–3 W each, with backlighting – up to 6 W. Water cooling (AIO) can draw 15–30 W, and a custom system – up to 50 W." |
| 여유분 | "most calculators automatically add a 20–30% buffer" |

그래서:

- 규칙 7의 출처 라벨에서 **「원문 미확인」을 뗀다**
- **이슈 #5가 풀린다.** 드라이브를 개당 **0~15W**로 넣는다. 원문은 상한만 주므로 하한은 0이다 —
  하한을 지어내지 않고, 최소 합계를 낮게 두는 쪽이 거짓 오류를 덜 낸다
- 쿨러·팬 값도 같은 원문에 있다. 별도 이슈로 넣는다
