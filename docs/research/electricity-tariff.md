# 전기요금 요율표 — 확보 실패, Phase 1 보류

스펙 §2.1이 **최우선 차별점**으로 꼽은 기능이다. 착수하려 했으나 요율표를 확보하지
못해 보류한다. **코드가 아니라 데이터에 막혔다.**

- 근거 문서: `pc-builder-spec.md` §2.1, §11(Phase 1), §12
- 같은 성격의 선례: `docs/research/power-constants.md`

---

## 1. 필요한 것

§2.1의 계산은 이렇다.

```
입력: 평소 월 전기 사용량(kWh) + PC 사용 패턴(게임 n시간/일, 아이들 m시간)
계산: PC 추가 사용량 → 기존 사용량에 합산 → 누진 구간 재계산
출력: 월 추가 요금, 누진 구간 상승 여부, 구간 상승 시 경고
```

**핵심은 PC 전력만 따로 계산하면 의미가 없다는 점이다.** 가구 전체 사용량에 PC
사용분이 얹히면서 구간이 넘어가는지가 실제 체감 요금을 결정한다.

그러려면 주택용 전력 요율표가 필요하다.

```
□ 주택용 저압 / 고압 구분
□ 구간별 기본요금과 전력량 요금
□ 계절별 구간 차이 (하계 별도 적용 여부)
□ 부가 항목 (기후환경요금, 연료비조정액, 부가세, 전력산업기반기금 등)
□ 최신 개정 시점
```

## 2. 왜 확보하지 못했는가

**이 실행 환경의 네트워크 정책이 한국전력 도메인을 차단한다.**

```
cyber.kepco.co.kr   연결 불가
home.kepco.co.kr    연결 불가
kepco.co.kr         연결 불가
```

`docs/research/power-constants.md`에서 `seasonic.com`·`crucial.com`이 막힌 것과 같은
제약이다.

## 3. 왜 추정하지 않는가

전력 상수(§power-constants)는 공개 자료가 **범위**로 존재해서 구간 판정이라는
우회로가 있었다. **요율표는 그렇지 않다.**

- 요율은 범위가 아니라 **정확한 공표값**이다. 추정할 성질의 수치가 아니다
- 누진 구간은 경계가 곧 결과다. 구간 경계를 1kWh만 틀려도 "구간이 올라간다/아니다"가
  뒤집힌다. 이 기능의 존재 이유가 바로 그 판정이다
- **돈에 직접 연결된다.** 사용자가 "월 3만원 더 나온다"를 보고 부품을 바꾼다.
  CLAUDE.md의 "근거 없는 수치를 지어내지 않는다"가 가장 강하게 적용되는 자리다
- 기억에 의존한 요율은 개정 시점을 알 수 없어 **틀렸는지조차 확인할 수 없다**

## 4. 지금 만들 수 있었던 것과, 만들지 않은 이유

요율표를 주입 가능한 데이터로 두고 계산 엔진만 먼저 만들 수는 있었다.
하지만 그러면 규칙 7이 겪은 상태가 반복된다 — 엔진은 있는데 데이터가 없어
전부 "판정 불가"인 화면. 실측(`opendb-schema-analysis.md` §9.3)에서 확인했듯
그 상태는 사용자에게 "덜 만들어진 도구"로 보인다.

**요율표가 확보되는 시점에 엔진과 함께 만드는 편이 낫다.** 계산 자체는 며칠 일이
아니다. 관문은 데이터다.

## 5. 해소 방법

셋 중 하나면 된다.

| 방법 | 내용 |
|---|---|
| **사용자가 요율표를 제공** | 한전 사이버지점의 주택용 요금표를 열어 §1의 항목을 전달. 가장 빠르다 |
| 네트워크 정책에 한전 도메인 허용 | 환경 설정 변경. 이후 갱신도 자동화할 수 있다 |
| 공공데이터포털 API | 요율 정보 제공 여부 확인 필요. 키 발급이 사용자 작업이다 |

확보되면 `source_url`과 개정 시점을 함께 저장한다 (§5.5). **요율은 개정되므로
갱신 주기도 정해야 한다** — §12의 "전기요금 요율표 출처 및 갱신 주기"가 그 항목이다.

## 6. 그래서 무엇을 먼저 했는가

Phase 1의 다른 항목(쿨러·스토리지 추가)은 부품 종류를 늘리는 일이라 규칙 9~11이
함께 필요하고, 그중 규칙 10(라디에이터)은 §4.2에서 이미 Phase 2로 미뤄져 있다.

대신 **§8의 부품 상세 페이지**로 갔다. 막히는 것이 없고, §5.5의 오류 신고 루프를
열어 현재 최대 개선 지점인 케이스 데이터 보강(판정 불가의 83.3%)에 직접 기여한다.
