# 네이버 쇼핑 검색 API — 종료 확인

조사일: 2026-09-23. 이슈 #1(국내 유통 매칭)·#8(약관)의 전제를 확인한 기록이다.

## 1. 결론

**명세 §5.7.1의 매칭 파이프라인은 네이버 쇼핑 API로는 성립하지 않는다.**

- 쇼핑 검색 API(`/v1/search/shop.json|xml`)는 **2026-07-31에 종료**됐다. 대체 API는 없다
- 남은 검색 API도 **2026-09-07 시행 약관**이 결과의 복제·저장·캐싱과 **AI 입력**을 금지한다.
  `skus`에 결과를 저장하는 설계는 다른 검색 API로 옮겨도 금지다

## 2. 직접 확인한 것

사용자가 발급한 키로 이 환경에서 호출했다 (네트워크 허용 후).

| 요청 | 결과 |
|---|---|
| `GET /v1/search/blog.json` | **200** — 인증·검색 API 권한 정상 |
| `GET /v1/search/shop.json` | **404 `SE05` Invalid search api (존재하지 않는 검색 api 입니다.)** |
| `GET /v1/search/shop.xml` | 404 `SE05` |

같은 키로 블로그는 되고 쇼핑만 「존재하지 않는 API」다. 키·권한 문제가 아니라 엔드포인트가 없어졌다.
개발자센터의 쇼핑 검색 문서는 아직 그대로 남아 있다 — **문서가 살아 있어도 API는 없다.**

## 3. 공개 자료

- 쇼핑·책·전문자료 검색 API는 2026-07-31 완전 종료, 공식 대체 없음. 일반 검색(블로그·뉴스·카페 등)과
  검색어 트렌드·쇼핑 인사이트는 NAVER API HUB로 이관, 기존 키 유예 2027-06-30까지.
  쇼핑 인사이트는 카테고리·키워드별 **상대 클릭 비율**이라 상품명·가격·상품 URL을 대신하지 않는다
  — [와플보드: 네이버 검색 API 종료? 살아남는 API와 NAVER API HUB 이관 방법](https://waffleboard.io/blog/naver-search-api-hub-migration-guide)
- 2026-09-07 시행 개정 약관: AI에 데이터를 입력하거나 학습·개선·평가·노출에 활용하는 행위,
  제3자 제공·판매, **복제·저장·캐싱**, 광고 수익화 금지. 개발자센터 신규 이용 신청은 2026-07-30 중단,
  무료 이용은 API HUB 종량제로 전환 예정
  — [한국데이터경제신문: 네이버, 9월부터 검색 API 'AI 활용 금지'](https://www.dataeconomy.co.kr/news/articleView.html?idxno=42307)
- 쇼핑 검색 API 종료 공지에 관한 개발자 문의 — [naver/naveridlogin-API #81](https://github.com/naver/naveridlogin-API/issues/81)

네이버 공지 원문은 자바스크립트로 그려져 이 환경에서 본문을 읽지 못했다. 위 자료와 §2의 직접 확인이 서로 맞는다.

## 4. 영향

| 대상 | 영향 |
|---|---|
| 이슈 #1 (국내 유통 매칭) | 설계 전제(네이버 쇼핑 API) 소멸. **다른 소스가 필요하다** |
| 이슈 #8 (약관) | 답이 나왔다 — 저장·캐싱 금지. 쇼핑은 그 전에 API 자체가 없다 |
| 명세 §5.7.1 | 3단계(네이버 쇼핑 조회)를 대체할 소스가 정해질 때까지 보류. **문서를 먼저 고친다 (작업 규칙 2)** |
| 검증 호출 | 블로그 1회, 쇼핑 실패 몇 회. 약관의 AI 입력 금지 때문에 **이후 호출하지 않는다** |

## 5. 다음 결정 (사람 몫)

국내 유통 판정의 소스를 새로 정해야 한다 — 후보 조사는 `domestic-availability-sources.md`. 후보마다 약관을 먼저 읽는다 — 이번처럼 설계 후에
알게 되면 파이프라인을 다시 짠다.

- 오픈마켓 제휴 API(쿠팡 파트너스·11번가 등): 저장·표시 조건과 호출 한도 확인 필요
- 수동 큐레이션: 국내 인기 부품 수백 개를 사람이 「유통 중」으로 표시 (§5.4의 초기 100개 선정과 겹친다)
- 유통 판정 없이 가기: OpenDB 전체를 보여주고 「국내 유통 여부 확인 안 됨」을 적는다
