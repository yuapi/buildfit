# 스펙 값 이상치 훑기 — 무엇을 고쳤고, 무엇을 두었나 (2026-09-24)

규칙 입력인 수치 필드의 분포 끝을 대표 레코드(`duplicate_of`가 없는 것)에서 훑었다.
**고친 것은 하나다** (§1). 나머지는 판정에 해가 없거나, 가를 신호가 없어서 두었다 (§2).
다음에 같은 조사를 다시 하지 않게 여기 남긴다.

방법: 필드마다 최솟값·최댓값을 보고, 끝의 레코드 이름을 읽었다. 그다음 무작위 견적 3,000개로
규칙별 비율을 봤다 (이슈 #29에서 쓴 방법).

## 1. 고친 것 — 메인보드 M.2 0개 (이슈 #33)

무작위 견적에서 규칙 17의 오류는 29건(1.0%)이었다. 그 보드들을 읽어 보니 ASRock X570 Taichi와
ASUS ProArt Z490-CREATOR 10G가 있었다 — 둘 다 M.2 슬롯이 있는 보드다.

이 레코드들은 PCIe 목록도 비어 있어서, 둘 다 비면 판정 불가로 둔다.
→ `storage-slots.md` §4.5, `compat-rules.md` §17.6

### 2.1 GPU TDP — 커넥터 공급 한계와 맞대 보았지만 모순 신호가 아니다

**RTX 3060 Ti의 750W는 틀렸다.** 권장 파워 용량이 들어간 것으로 보인다. 규칙 7이 이 값으로
전력을 추정하므로, 흔한 550~650W 파워와 짝지으면 거짓 오류가 난다.

그래서 **경계값 없이** 가를 방법을 찾아봤다. PCIe 사양의 커넥터 공급 한계와 비교하는 것이다
(슬롯 75W, 6핀 75W, 8핀 150W, 16핀 600W). 이 한계를 넘는 대표 레코드는 **19건**이다.
그런데 셋으로 갈린다.

| 무리 | 예 | 무엇이 틀렸나 |
|---|---|---|
| TDP가 틀렸다 | RTX 3060 Ti 750W (8핀 2개), RX 6750 XT Red Devil 700W | TDP |
| 커넥터가 틀렸다 | MSI RTX 5080 3종 360W (8핀 1개로 적힘, 실제 16핀), Palit RTX 5090 575W (8핀 2개로 적힘) | 커넥터 |
| **둘 다 맞다** | AMD R9 295X2 500W (8핀 2개) — AMD가 사양 한계를 넘겨 설계했다. RTX A6000 300W — 8핀이 PCIe가 아니라 EPS(300W)다. Quadro M6000 250W · RTX A5000 230W (8핀 1개) — 한계를 조금 넘는 설계다 | 없음 |

셋째 무리가 있어서 **「사양 한계를 넘는다 = 모순」이 성립하지 않는다.** 이것을 검증 신호로
쓰면 맞는 값에 「검증 중」이 붙는다. 같은 칩의 다른 카드와 비교하는 방법도 있지만, 몇 배를
이상치로 볼지가 근거 없는 경계값이 된다.

**그래서 두었다.** 틀린 값은 사용자 신고와 `/admin` 보강으로 고친다.
