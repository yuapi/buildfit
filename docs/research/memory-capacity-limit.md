# 총 메모리 용량 한계 — 규칙 16의 근거

조사일: 2026-09-22. 대상: 적재된 카탈로그 (BuildCores OpenDB).
RAM 4,876건 · 메인보드 3,701건 · CPU 789건.

## 1. 질문

`memory_max_gb`가 CPU와 메인보드 양쪽에 적재돼 있고 부품 화면에 「최대 메모리」로
표시까지 된다. 그런데 **어떤 규칙도 이 값을 쓰지 않는다.**

규칙 2는 DDR 규격을, 규칙 3은 모듈 수를 본다. 용량은 아무도 안 본다.
128GB까지인 보드에 192GB 킷을 넣어도 "문제 없음"으로 나온다.

## 2. 결론

**판정할 수 있고, 지금까지 만든 규칙 중 데이터가 가장 잘 채워져 있다 (판정 불가 0.27%).**

| 쪽 | 필드 | 채워짐 |
|---|---|---|
| RAM | `capacity_gb` | 4,876 / 4,876 (100%) |
| CPU | `memory_max_gb` | 789 / 789 (100%) |
| Motherboard | `memory_max_gb` | 3,694 / 3,701 (99.8%) |

## 3. 규칙 2·3이 통과시키던 것을 잡는다

RAM 4,876 × 보드 3,701 = **18,046,076 조합**.

| | 조합 수 | 비율 |
|---|---|---|
| 용량 판정 불가 | 48,760 | 0.27% |
| 용량 초과 (전체 기준) | 2,061,613 | 11.4% |
| 규칙 2·3을 통과 | 6,316,250 | — |
| **그중 용량 초과** | **75,497** | **1.20%** |

마지막 줄이 이 규칙의 값어치다. 75,497건은 **지금 이 도구가 전부 "문제 없음"으로
보여 주는 조합**이다. 나머지 초과분은 대개 DDR 규격이 달라 규칙 2가 이미 잡는다.

## 4. CPU도 봐야 한다

소켓이 맞는 CPU × 보드 264,679 조합에서 두 최대값을 비교했다.

| 관계 | 조합 수 | 비율 |
|---|---|---|
| **CPU가 더 낮다** | **37,667** | **14.2%** |
| 보드가 더 낮다 | 114,879 | 43.4% |
| 같다 | 107,823 | 40.7% |

**보드만 보면 14.2%를 놓친다.** 한계는 둘 중 작은 쪽이다.

```
한계 = min(보드 최대, CPU 최대)
총 용량(킷 합계) > 한계  →  경고
```

킷이 여럿이면 용량을 더한다. 규칙 3이 모듈 수를 더하는 것과 같다.

## 5. 오류가 아니라 경고다

제조사의 최대 메모리 사양은 **보수적이고 BIOS 업데이트로 늘어난다.** AM4 보드가
대표적이다. 오류로 단정하면 실제로 쓸 수 있는 조합을 막는다.

규칙 9(쿨러 높이)에서 같은 이유로 경고를 택한 전례가 있다 (`docs/compat-rules.md` §9.1).
"안 된다"가 아니라 "확인이 필요하다"로 말한다.

## 6. 이상치 — 작은 값을 거르면 안 된다 ★

`memory_max_gb`가 작다고 이상치로 볼 수 없다. **작은 값이 맞는 보드가 실재한다.**

| 최대 | 보드 수 | 예 |
|---|---|---|
| 2 | 1 | Jetway Atom N550 Mini ITX (DDR3, 2슬롯) — 맞다 |
| 4 | 21 | LGA775 G31/G41, Atom D525 (DDR2·DDR3, 2슬롯) — 맞다 |
| 8 | 53 | |
| 16 | 180 | |

대신 **슬롯 수와 맞대 본다.** 모든 실제 DIMM이 1GB 이상이므로, 최대 용량이 슬롯 수보다
작을 수는 없다. 이 검사가 걸러 내는 것은 정확히 다음 5건이다.

| 보드 | 최대 | 슬롯 | 규격 |
|---|---|---|---|
| ASRock X570 Taichi | 0 | 4 | DDR4 |
| ASRock X399 Taichi | 0 | 8 | DDR4 |
| MSI MEG X399 CREATION | 0 | 8 | DDR4 |
| ASUS PRIME H570-PLUS | 1 | 4 | DDR4 |
| ASUS Pro WS TRX50-SAGE WIFI | 1 | 4 | DDR5 |

**맞는 값은 하나도 걸리지 않고 틀린 값은 전부 걸린다.** 단순한 하한선(예: 8GB 미만
버리기)으로는 LGA775 보드 22건이 함께 사라진다.

§8.4의 모순 검사와 같은 종류다 — 값 하나만 보면 그럴듯한데 다른 필드와 맞대 보면 틀렸다.

CPU 쪽은 슬롯이 없으니 `0` 이하만 본다 (48건).

## 7. 다시 재야 할 때

- 카탈로그가 커지면 §3·§4·§6을 다시 잰다
- 업스트림이 위 5건을 고치면 §6의 예시 표를 다시 본다. 검사 자체는 남긴다
- **DIMM 하나당 최대 용량** 필드가 생기면 규칙을 나눈다. 지금은 총량만 본다 —
  32GB DIMM까지인 보드에 48GB DIMM을 꽂는 경우는 총량으로 잡히지 않는다
