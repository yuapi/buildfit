# 국내 유통 판정 — 네이버 이후의 소스 후보

조사일: 2026-09-23. 이슈 #1(국내 유통 매칭)의 소스를 다시 찾은 기록이다.
전제: 네이버 쇼핑 검색 API는 종료됐다 (`naver-shopping-api-status.md`).

## 1. 결론

**판매자가 아닌 개발자가 쓸 수 있는 쇼핑 검색 API는 없다.** 대규모 매칭(부품 약 26,000건)이
가능했던 마지막 후보인 11번가 상품검색도 **키 발급이 판매자 회원만 가능하다** (2026-09-23 사용자
확인, §2). API로 유통을 판정하는 경로는 지금 모두 막혀 있다.

| 후보 | 상태 | 대량 매칭 | 막힌 곳 |
|---|---|---|---|
| **11번가 상품검색** (`ProductSearch`) | **살아 있다** — 호출하면 「등록되지 않은 키」가 온다 | 가능 (한 번에 최대 200건) | **키 발급이 판매자 회원만 가능하다** (사용자 확인). 일일 한도·저장 조건 미확인 |
| 쿠팡 파트너스 검색 | 살아 있다 | **불가** — 시간당 10회, 위반 1회에 24시간 차단 | 한도 |
| 다나와 OPEN API | **죽었다** — `api.danawa.com` 호스트 이름이 조회되지 않는다 | — | — |
| 카카오(다음) 쇼핑 검색 | **없다** — 카카오 직원이 「제공하지 않는다」고 답했다 (2026-04) | — | 남은 다음 검색 API도 외부 LLM 전달을 제한한다 (2026-09) |
| 카카오쇼핑 모델명 검색 | 판매자용 상품 등록 API | — | 판매자 전용으로 보인다 |
| KC 적합성평가 (국립전파연구원) | 살아 있다. 무료·자동 승인·이용 범위 제한 없음 | **불가** — **인증번호로만** 조회한다 | OpenDB에 인증번호가 없다. 모델명·기간으로 검색하는 연산이 없다 |
| 조달청 물품목록정보 | 살아 있다. 무료·자동 승인·이용 범위 제한 없음 | — | 공공조달 목록이다. 소매 유통 여부가 아니다 |

## 2. 11번가 상품검색 — 직접 확인한 것

개발 가이드(`OpenApiGuide.tmall?categoryNo=54&apiSpecType=1`):

- 요청: `http://openapi.11st.co.kr/openapi/OpenApiService.tmall?key=…&apiCode=ProductSearch&keyword=…`
- 파라미터: `pageNum`, `pageSize`(기본 50, **최대 200**), `sortCd`(인기도·판매·가격·최신 등),
  `targetSearchPrd`(KOR/ENG)
- 응답: 상품코드·상품명·이미지·상세 URL·가격·판매자·평점·할인가·배송·리뷰 수 등. **EUC-KR XML**
- 오류 코드에 `004 overedTraffic`(하루 호출 가능 횟수 초과)이 있다. **일일 한도가 있지만 수치는 공개돼 있지 않다**
- 이 환경에서 임의의 키로 호출하면 `003 unregisteredKey`가 온다. **엔드포인트는 살아 있다**
- 2026-06-30부터 키 유효기간이 180일이다 (공지 2026-06-24). 공지 게시판은 2026-09에도 갱신되고 있다

**키 발급은 판매자 회원만 가능하다** — 사용자가 확인했다 (2026-09-23).
공개 자료와도 맞는다: 키 발급 안내 글은 전부 셀러 계정 기준이고, 서비스 소개 페이지의 API 목록도
판매자용(상품·주문·클레임 등)뿐이며, 상품검색은 예전 가이드에만 남아 있다.

확인하지 못한 것 (키가 없어 볼 수 없다):

- 약관 — 결과의 저장·캐싱, 상업적 이용, AI 입력. 로그인 뒤에만 보인다
- 일일 한도 수치

**단일 몰이다.** 11번가에 없다고 국내에 유통되지 않는다는 뜻이 아니다. 판정 문구가 그 차이를 적어야 한다
(「11번가에서 판매 중」 ≠ 「국내 유통」).

## 3. 탈락 근거

- **쿠팡 파트너스**: 시간당 10회면 하루 240회다. 26,000건을 매칭하려면 100일이 넘게 걸린다
- **다나와**: 가이드 페이지(`img.danawa.com/new/open_api/api_guide.html`)는 남아 있지만 거기 적힌
  `api.danawa.com`이 DNS에서 조회되지 않는다. API Store 페이지는 503이다
- **KC 인증**: `getAuthInfo`·`getAuthStatus` 두 연산 모두 필수 파라미터가 `mtlCefNo`(인증번호) 하나다.
  응답에 기본 모델명·파생 모델명이 있지만 거꾸로 모델명으로 찾는 연산은 없다. 웹 검색 화면은
  모델명 검색과 CSV 내려받기를 지원하지만 reCAPTCHA가 걸려 있다 — 자동으로 긁지 않는다
- **KC 인증은 유통을 증명하지도 않는다.** 인증을 받았다는 사실이 지금 팔린다는 뜻은 아니다

## 4. 다음 결정 (사람 몫)

1. ~~11번가 키 발급~~ — **판매자 회원만 가능해 막혔다.** 판매자로 가입하는 것은 이 도구의 목적
   (판매가 아니라 판단)과 맞지 않고, 가입해도 약관(저장·캐싱)을 확인하기 전에는 설계가 서지 않는다
2. **수동 큐레이션** — 국내 인기 부품 수백 개에 사람이 「유통 중」을 표시한다. API 의존이 없다
3. **유통 판정 없이 가기** — 「국내 유통 여부 확인 안 됨」을 적는다

어느 쪽이든 명세 §5.7.1을 먼저 고치고 승인을 받는다 (작업 규칙 2).
