# 부품 이미지 소스 조사

- 조사일: 2026-09-20
- 질문: 부품 22,962건에 쓸 수 있는 **라이선스가 분명한** 제품 이미지 소스가 있는가
- 결론: **전수를 덮는 소스는 없다.** 그리고 이 제품에는 사진이 최우선이 아니다 (§6)

## 0. 조사의 한계 — 먼저 밝힌다

이 작업 환경의 egress 정책에서 **후보 사이트 대부분이 차단돼 있다.**

```
icecat.biz, api.icecat.biz, commons.wikimedia.org, developers.naver.com,
danawa.com, quasarzone.com, pcpartpicker.com, newegg.com  → 전부 연결 불가
```

따라서 **약관 원문을 직접 읽지 못했다.** 아래는 검색 결과에 인용된 조항과
공개된 요약에 근거한 것이고, 출처를 함께 적었다. **계약 판단의 근거로 쓰기
전에 원문을 확인해야 한다.** 특히 §2의 네이버 조항이 그렇다.

## 1. 1차 소스에는 없다 (확정)

BuildCores OpenDB 전수 확인 결과다.

- 레코드에 이미지·사진·에셋 필드가 **하나도 없다** (CPU·GPU·PCCase 표본 900건에서 키 전수 수집)
- 레포의 `assets/`는 `gpu.png`, `opendb.png` 두 장뿐이다 (로고·배너)

즉 지금 구조로는 이미지를 넣을 자리 자체가 없다. 소스를 따로 구해야 한다.

## 2. 네이버 쇼핑 API ⚠️ **이슈 #1 설계에 영향**

가장 손쉬운 후보였다. 쇼핑 검색 결과에 상품 이미지 URL이 딸려 온다.

그런데 네이버 API 이용약관에 **결과 데이터를 저장·DB화하지 말라**는 조항이 있다.

> API 결과 데이터는 별도로 저장해서는 안되며, 그와 같은 결과 데이터를 별도로
> 저장하는 방식으로 데이터베이스화하여 이용해서도 안됩니다.
>
> — [네이버 클라우드 플랫폼 AI·Naver API 서비스 이용약관](https://xv-ncloud.pstatic.net/images/provision/AI%C2%B7NaverAPI%EC%84%9C%EB%B9%84%EC%8A%A4%EC%9D%B4%EC%9A%A9%EC%95%BD%EA%B4%80_1620716044568.pdf)

이게 사실이라면 이미지만의 문제가 아니다.

- **이미지**: 내려받아 우리 CDN에 두는 것은 안 된다. 요청 시점에 받아 그때만
  쓰는 것으로 제한된다
- **이슈 #1 (국내 유통 매칭)**: 명세 §5.7.1은 매칭 결과를 `skus` 테이블에
  **저장**하는 설계다. 이 조항과 정면으로 부딪힌다

> **[확인 필요]** 위 인용은 클라우드 플랫폼 약관이고, 검색 API(개발자센터)
> 약관과 범위가 다를 수 있다. 인용문 안의 "1회 사용" 제한은 Maps API를
> 가리키는 문장이었다. **developers.naver.com이 차단돼 원문을 읽지 못했다.**
> 이슈 #1을 시작하기 전에 이것부터 확인해야 한다 — 설계가 바뀔 수 있다.
> 별도 이슈로 열어뒀다: [#8](../../issues/8)

## 3. Open Icecat — 가장 현실적인 유료 아닌 선택지

브랜드가 후원한 제품에 한해 **제품 정보와 이미지를 무료로** 개방하는 카탈로그다.
PC 부품 브랜드(ASUS·MSI·Corsair 등)는 대체로 참여하는 편이라 커버리지가 기대된다.

- 라이선스: Open Icecat Content (OIC) License. **API를 통한 자동 접근이 명시적으로 허용**된다
- 조건: 무료 **등록 필요**, 사용량 정보를 저작권자(브랜드)에게 제공하는 데 동의,
  Fair Use Policy 준수
- 출처: [Open Content License](https://iceclog.com/open-content-license/) ·
  [FAQ](https://iceclog.com/faq-for-icecat-product-content-users/) ·
  [JSON API 매뉴얼](https://iceclog.com/manual-for-icecat-json-product-requests/)

**우리 데이터와 맞물린다.** Icecat은 EAN/UPC/GTIN으로 조회할 수 있고,
OpenDB 레코드에 `identifiers`(ean·upc·mpn)가 들어 있다. 매칭 키가 이미 있다.

**확인해야 할 것**

- [ ] 커버리지 — 우리 22,962건 중 몇 건이 Open(무료) 구간에 있는가.
      후원하지 않는 브랜드는 Full Icecat(유료)로 빠진다
- [ ] 이미지 재호스팅 가능 여부. 핫링크만 허용인지, 내려받아 둬도 되는지
- [ ] 한국어 제품명 제공 여부 (없어도 우리는 모델명을 쓰므로 무방)

## 4. 제조사 공식 이미지

우리는 이미 **제조사 스펙 페이지 주소를 4,201건** 갖고 있다 (`parts.manufacturer_url`).
거기 이미지가 있다.

- 저작권은 제조사에 있다. **블랭킷 허용이 아니다**
- 다만 상당수 제조사가 프레스/파트너 키트로 제품 이미지 사용을 명시 허용한다.
  브랜드마다 조건이 다르므로 **브랜드 단위로 확인**해야 한다
- 현실적 접근: 국내 유통 상위 브랜드 10~20곳만 먼저 확인한다.
  전수를 덮으려 하지 않는다

## 5. Wikimedia Commons — 커버리지가 없다

CC 라이선스라 조건은 가장 깨끗하지만 **양이 없다.**

- `Category:Central processing units`에 **107개 파일**. 우리는 CPU만 789건이다
- 내용도 역사적·교육적 표본 위주다 (ETA10 슈퍼컴퓨터, GeForce 2MX …)
- 출처: [Category:Central processing units](https://commons.wikimedia.org/wiki/Category:Central_processing_units) ·
  [Quality images of computer hardware](https://commons.wikimedia.org/wiki/Category:Quality_images_of_computer_hardware)

→ 전수용으로 쓸 수 없다. 대표 부품 몇 개에만 쓸 수 있다.

## 6. ★ 그런데 이 제품에 사진이 최우선인가

다나와·PCPartPicker가 썸네일을 크게 쓰는 이유는 **파는 곳**이기 때문이다.
사진은 구매 결정을 돕는다.

이 프로젝트는 명시적으로 가격비교가 아니다 (ADR-0006). 사용자가 여기서 하는 결정은
**"이 조합이 맞는가"**이고, 그 결정에 제품 사진은 거의 기여하지 않는다.
RTX 5080 사진을 본다고 케이스에 들어가는지 알 수 없다.

**사진보다 이 제품에 맞는 시각 요소가 있다.**

| 후보 | 근거 데이터 | 있나 |
|---|---|---|
| **GPU 길이 vs 케이스 한계를 실척으로 그리기** | `length_mm`, `max_gpu_length_mm` | ✅ 95.5% / 95.7% |
| **쿨러 높이 vs 케이스 한계** | `height_mm`, `max_cpu_cooler_height_mm` | ✅ 70.4% / 35.2% |
| **소비전력 구간 vs 파워 정격 막대** | `estimatePower`, `wattage_w` | ✅ 이미 계산한다 |
| 커넥터 충족 도식 | GPU·PSU 커넥터 수 | ✅ 규칙 8이 쓴다 |

전부 **이미 가진 데이터**고, 라이선스 문제가 없고, 경쟁 사이트가 하지 않는 것이다.
"빠듯하게 들어감"을 문장으로 읽는 것보다 막대 두 개로 보는 쪽이 빠르다.

## 7. 권고

1. **먼저 §6을 한다.** 라이선스 없이, 가진 데이터로, 이 제품에만 있는 시각 요소를 만든다
   → **착수함.** `케이스 여유` 패널 (`apps/web/src/components/FitBar.tsx`).
   GPU 길이·쿨러 높이를 케이스 한계와 실척 막대로 비교한다.
   "빠듯함" 기준은 **규칙마다 다르므로 호출부가 건넨다** — 규칙 4는 95%,
   규칙 9는 빠듯함을 알리지 않는다 (§9.3). 만들면서 실제로 이 둘이 어긋나
   막대가 규칙보다 더 말하고 있었고, 테스트로 고정했다
2. **이슈 #1 전에 §2의 네이버 약관 원문을 확인한다.** 유통 매칭 설계가 바뀔 수 있다
3. 사진이 필요하다고 판단되면 **Open Icecat 커버리지를 먼저 측정한다.**
   EAN/MPN이 이미 있으니 표본 100건으로 적중률을 재면 된다
4. 제조사 이미지는 **브랜드 단위 확인** 없이 쓰지 않는다
5. Wikimedia는 전수 소스가 아니다. 안내 페이지의 대표 이미지 정도로만
