# 한전 주택용 전기요금표

조사일: 2026-09-22.
출처: 한전 사이버지점 `cyber.kepco.co.kr` — 업무찾기 › 주택용전력 요금 누진제.
**사용자가 직접 열어 캡처한 화면을 받았다.** 이 실행 환경의 네트워크 정책이
한전 도메인을 차단해 그때까지 확보할 수 없던 표다 (이슈 #2).

화면 사본: `docs/research/sources/kepco-residential-2026-09-22.jpg`

## 1. 누진제란

> 누진제도는 사용량이 증가함에 따라 순차적으로 높은 단가가 적용되는 요금으로,
> 현재 200kWh 단위로 3단계, 최저와 최고간의 누진율은 2.7배로 운영되고 있습니다.

원문의 예시가 계산식을 확정해 준다.

> 기타계절에 월 300kWh를 사용한 가정은 처음 200kWh에 대해서는 kWh당 120.0원이
> 적용되고, 나머지 100kWh에 대해서는 214.6원이 각각 적용돼 총 45,460원의
> 전력량요금이 부과됩니다.

```
200 × 120.0 = 24,000
100 × 214.6 = 21,460
              45,460  ✓
```

**구간마다 단가가 다르고, 넘은 만큼에만 다음 단가를 쓴다.** 전체에 최고 단가를
적용하는 방식이 아니다.

### 1.1 ★ 본문의 「2.7배」와 표가 어긋난다

본문은 "최저와 최고간의 누진율은 2.7배"라고 적었는데 표의 값으로는
`307.3 / 120.0 = 2.56배`다. 단가가 개정되고 설명문이 따라오지 않은 것으로 보인다.

**표를 따른다.** 계산에 쓰는 것은 단가이고 비율은 설명문이다. 원문 예시
(300kWh → 45,460원)가 표의 단가로 정확히 맞으므로 표가 현행이다.

## 2. 주택용전력 (저압)

### 2.1 기타계절 — 1월 1일~6월 30일, 9월 1일~12월 31일

| 기본요금 (원/호) | | 전력량요금 (원/kWh) | |
|---|---|---|---|
| 200kWh 이하 사용 | 910 | 처음 200kWh까지 | 120.0 |
| 201~400kWh 사용 | 1,600 | 다음 200kWh까지 | 214.6 |
| 400kWh 초과 사용 | 7,300 | 400kWh 초과 | 307.3 |

### 2.2 하계 — 7월 1일~8월 31일

| 기본요금 (원/호) | | 전력량요금 (원/kWh) | |
|---|---|---|---|
| 300kWh 이하 사용 | 910 | 처음 300kWh까지 | 120.0 |
| 301~450kWh 사용 | 1,600 | 다음 150kWh까지 | 214.6 |
| 450kWh 초과 사용 | 7,300 | 450kWh 초과 | 307.3 |

**하계는 구간이 넓다.** 단가는 같고 경계만 200/400 → 300/450으로 옮겨진다.
에어컨 때문에 여름에 누진을 완화한 것이다.

### 2.3 슈퍼유저요금

| 기간 | 조건 | 단가 |
|---|---|---|
| 동계 (12월 1일~2월 말일) | 1,000kWh 초과 | 736.2원/kWh |
| 하계 (7월 1일~8월 31일) | 1,000kWh 초과 | 736.2원/kWh |

**동계가 따로 있다.** 기타계절(1~6월, 9~12월) 안에서도 12·1·2월만 이 단가가 붙는다.
즉 계절 구분이 두 겹이다 — 구간 경계는 하계/기타계절 두 갈래, 슈퍼유저는
하계/동계/그 외 세 갈래.

## 3. 담지 않는 것 ★

실제 청구액에는 아래가 더 붙는다. **이 표에 없는 값은 담지 않는다.**

| 항목 | 왜 안 담는가 |
|---|---|
| 기후환경요금 | 화면의 아파트 예시에 `5.3원/kWh`가 보이지만 **2021년 1월 기준 예시**다. 분기마다 바뀐다 |
| 연료비조정요금 | 같은 예시에 `-3원/kWh`. 분기마다 바뀌고 부호도 바뀐다 |
| 부가가치세 | 이 화면에 없다 |
| 전력산업기반기금 | 이 화면에 없다 |

그래서 이 표로 낸 값은 **실제 청구액보다 낮다.** 그 방향을 결과에 적는다 —
규칙 7이 스토리지 전력을 빼면서 그렇게 하는 것과 같다 (`compat-rules.md` §7.4.1).

## 4. 고압은 담지 않는다

받은 화면에 고압 표도 있으나 **적용일자가 2021년 1월 1일**이고 단가가 저압 현행과
다르다 (저압 88.3/182.9/275.6 · 고압 73.3/142.3/210.6). 지난 표다.

고압은 아파트 단일계약·종합계약에서 쓰이고, 그 경우 세대 요금은 관리주체가
산정해 관리비로 청구한다 — 사용자가 직접 확인할 수 있는 값이 아니다.
**저압만 담는다.**

## 5. 갱신 주기

단가는 정부 인가로 바뀌고 예고 없이 개정된다. `[미확정]`이던 §11의
"전기요금 요율표 출처 및 갱신 주기" 중 **출처는 확정됐다.** 주기는 고정된 것이
없으므로 표에 **확인한 날짜를 함께 담고 화면에 그 날짜를 적는다.**

## 6. 이 표로 무엇을 계산하는가

명세 §2.1이 정한 것 그대로다.

```
입력: 평소 월 사용량(kWh) + PC 사용 패턴
계산: PC 추가 사용량 → 기존 사용량에 합산 → 누진 구간 재계산
출력: 월 추가 요금, 누진 구간 상승 여부
```

**PC 전력만 따로 곱하면 의미가 없다.** 같은 100kWh가 붙어도 가구가 150kWh를
쓰던 집과 380kWh를 쓰던 집의 추가 요금이 다르다. 누진 구간을 넘는지가 체감을
결정한다.

PC 소비전력은 구간(min~max)이므로 요금도 구간이다 (ADR-0004).
