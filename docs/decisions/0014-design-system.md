# ADR-0014: 디자인 시스템 — 색은 판정에만 쓴다

## 상태
채택 (2026-09-19). **결정 1은 ADR-0015가 수정했다** — 브랜드 색을 크롬에
한해 허용한다. 본문·판정 영역에 대한 규칙은 그대로다.

## 배경

기능은 전부 도는데 화면이 프로토타입 상태다 (이슈 #6).

- `layout.tsx`가 create-next-app 기본값 그대로다. `lang="en"`, 제목 "Create Next App",
  `body { font-family: Arial }`가 Geist를 덮고 있다. **한국어 사이트인데 영어로 선언돼 있다**
- 디자인 토큰이 없다. 색·간격·타이포가 파일마다 즉흥적이다
- 공통 헤더·푸터가 없어 페이지마다 따로 떨어진 문서처럼 보인다
- `dark:` 클래스가 모든 색 선언마다 붙어 두 벌을 손으로 맞추고 있다
- 판정 패널이 이 도구의 핵심인데 사이드 메모처럼 보인다

## 결정

### 1. 색은 판정에만 쓴다 ★

> **수정됨 (ADR-0015).** 규칙을 장소로 좁혔다. 헤더·푸터·로고에서는 브랜드 색을
> 쓴다. **본문과 판정 영역에서는 아래 그대로다.**

**장식으로 색을 쓰지 않는다.** 빨강·노랑·파랑·초록은 각각 오류·경고·정보·통과를
뜻하고, 그 외 어디에도 나타나지 않는다. 브랜드 색도 두지 않는다.

- 기본 화면은 무채색이다. 버튼도 무채색(거의 검정)이다
- 사용자가 색을 본 순간 그것은 **판정 결과**다
- 링크는 색이 아니라 밑줄로 구분한다

### 2. 색은 CSS 변수로 두고 `dark:`를 쓰지 않는다

의미 토큰(`--color-surface`, `--color-danger` …)을 `:root`에 정의하고
다크 모드에서 값만 바꾼다. 컴포넌트는 `bg-surface` 하나만 쓴다.

`dark:` 클래스를 색마다 붙이면 두 벌을 손으로 맞춰야 하고, 실제로 한쪽만
고치는 일이 생긴다. 토큰이면 그럴 수 없다.

### 3. 다크 모드는 시스템을 따르되 전환할 수 있다

`prefers-color-scheme`이 기본이고, `<html data-theme>`로 덮어쓴다.
선택은 `localStorage`에 남긴다 (add-only, ADR-0005).

**첫 페인트 전에 인라인 스크립트로 적용한다.** 그러지 않으면 밝은 화면이
한 번 번쩍인다.

### 4. 공통 셸

헤더(로고·네비)·푸터·컨테이너 폭을 `layout.tsx`가 소유한다.
페이지는 본문만 쓴다. 출처 표기(ODC-By)는 푸터에 한 번만 둔다 —
부품 상세는 그 부품의 원본 링크를 따로 가지므로 거기 유지한다.

### 5. 한국어를 위한 타이포

- `lang="ko"`
- 본문 행간 1.7. 한글은 라틴보다 글자 밀도가 높아 1.5로는 답답하다
- 숫자·모델명은 라틴 폰트(Geist)가 먼저 잡고, 한글은 시스템 폰트로 떨어뜨린다.
  웹폰트로 한글 전체를 받으면 용량이 크고, 이 환경에서 외부 폰트 접근도 불확실하다
- `word-break: keep-all` — 한국어에서 단어 중간이 끊기지 않게 한다

## 이유

### 색을 아끼는 이유

이 도구가 하는 일은 판정이다. 화면에 파란 버튼과 초록 배지와 보라 강조가 있으면
초록 "통과"가 그중 하나로 묻힌다. **의미 없는 색을 쓰지 않는 것**이
"근거 없는 수치를 지어내지 않는다"(CLAUDE.md)와 같은 종류의 규율이다.

부수 효과로 브랜드가 타이포그래피와 여백으로만 만들어진다. 그게 이 제품의
성격(정확함, 과장 없음)과도 맞는다.

### 검토한 대안

| 대안 | 탈락 이유 |
|---|---|
| 브랜드 강조색(파랑 등)을 둔다 | 규칙 12의 "정보" 등급이 파랑이다. 브랜드색과 판정색이 겹친다 |
| 판정색을 아이콘·글자로만 표시 | 색맹 대응으로는 맞지만, 색을 빼면 한눈에 안 들어온다. **둘 다 한다** — 점 + 등급 라벨 텍스트 |
| Pretendard 등 한글 웹폰트 | 용량이 크고 외부 의존이 생긴다. 이 환경에서 외부 폰트가 막히면 화면이 깨진다 |
| `dark:` 유지 | 색 선언이 두 벌이 되고 한쪽만 고치는 사고가 난다 |

## 결과

- 새 색을 쓰려면 먼저 "이게 판정인가?"를 묻는다. 아니면 무채색이다
- 판정 등급은 **색과 텍스트 라벨을 함께** 낸다. 색만으로 구분하지 않는다 (WCAG 1.4.1)
- 토큰은 `apps/web/src/app/globals.css` 한 곳에 있다. 컴포넌트에 색 리터럴을 쓰지 않는다
- 대비는 라이트·다크 모두 본문 4.5:1 이상을 지킨다
