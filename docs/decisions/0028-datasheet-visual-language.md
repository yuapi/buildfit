# ADR-0028: 화면 언어를 검수 성적서로 — 카드 더미를 괘선과 칸으로

## 상태
채택 (2026-10-20). ADR-0014·ADR-0015의 색 규칙은 그대로다. 생김새(모서리·구획·타이포)만 바꾼다.

## 배경

ADR-0015 뒤에도 화면이 **템플릿처럼 보인다**는 평가를 받았다 (이슈 #133).
화면을 놓고 남은 서명을 따졌다.

1. **모든 것이 여전히 둥근 카드다.** 12px 모서리·옅은 그림자. 부품 표, 판정 옆 칸 넷,
   저장·공유, 견적서 붙여넣기 안내가 전부 따로 떠 있는 카드였다
2. **첫 화면이 흔한 히어로다.** 큰 제목 + 회색 문단 두 줄. 무엇이든 될 수 있는 생김새다
3. **검사 규칙 화면이 카드 20장이다.** 한 장의 표로 읽혀야 할 것이 흩어져 있었다
4. **헤더가 지금 어디인지 말하지 않는다.** 메뉴 넷이 다 같은 회색이었다
5. 옆 칸이 길어 **왼쪽 아래가 크게 비었다**

## 결정

이 도구가 내놓는 것은 **판정**이다. 그 생김새를 검수 성적서·데이터시트에서 빌린다.

### 1. 칸과 괘선
- `--radius-card: 0`, `--radius-control: 2px`, 그림자 없음. 떠 있는 카드가 아니라 괘선으로 둘러친 칸이다
- 판정 옆 칸 넷은 괘선을 겹쳐(`-mt-px`) **한 장**으로 잇는다. 부품 표와 옆 칸도 붙는다
- 저장·공유는 왼쪽 열 부품 표 밑에 붙인다. 좁은 화면에서는 열을 풀고 맨 끝으로 보낸다 — 판정 내역이 먼저다

### 2. 구획 머리
- `.panel-head`·`.card-head`: 제목 + 아래 괘선 하나
- 앞에 고정폭 약어 표식(`.idx`): BOM·PWR·KWH·FIT·CHK. **순번이 아니다** — 부품을 고르기 전엔
  일부 구획이 숨어서 「01 … 05」처럼 번호가 비었다
- 페이지 제목 위에 영문 장식 머리글을 두지 않는다. 같은 말을 영어로 한 번 더 하는 장식이었다 (이슈 #136)

### 3. 첫 화면 표제 칸
- 모눈 바탕(`.sheet-grid`) 위의 제목 + 오른쪽 사양 칸(검사 항목 수·지원 부품·데이터 누락 시 판정 불가 표시·회원가입 불필요)
- 수치는 지어내지 않는다. 검사 항목 수는 `RULE_SUMMARY`, 부품 종류는 `CATEGORY_LABELS`에서 센다
- 모눈은 괘선 토큰으로 그린다. 색이 아니다

### 4. 판정 띠는 도장
- 왼쪽 6px 막대 + 2xl 굵은 등급 문구(「호환 불가」「확인 필요」「모든 항목 통과」). 화면에서 가장 큰 글자다

### 5. 표는 표로
- 부품 카테고리: 번호 붙은 색인 표. 카테고리 목록: 모델 · 제조사 · 출시 칸
- 검사 규칙: 한 장의 표. 왼쪽 칸에 `R-01` 번호, 빈 비율을 무채색 막대로도 보인다

### 6. 크롬
- 헤더는 칸으로 나뉜 표제란. 지금 있는 메뉴에 브랜드 색 막대를 긋는다 (크롬이므로 허용, ADR-0015)
- 푸터는 셋으로 나눈 칸: 무엇인가 · 원칙 · 데이터 출처

### 7. 바탕
- 흰색 대신 종이색(라이트 `#f1efe8`), 잉크색 글자. 종이색 위에서 4.5:1을 넘기려고
  판정 글자색(통과·경고·정보)을 조금 짙게 했다. `contrast.test.ts`가 고정한다
- 기본 CSS: 빈 곳을 눌러도 입력 커서가 뜨지 않게, 조작 영역은 글자 선택을 막고, 얇은 스크롤바

## 검토한 대안

| 대안 | 탈락 이유 |
|---|---|
| 모서리만 줄인다 | 「모든 것이 같은 카드」는 그대로다. 구획을 잇고 표로 바꿔야 풀린다 |
| 본문에 강조색 | ADR-0014의 목적(통과 초록이 장식에 묻히지 않게)을 깬다 |
| 한글 웹폰트로 개성 | 용량·외부 의존 (ADR-0014). 굵기·자간·고정폭 숫자로 충분하다 |
| 구획에 순번 | 부품을 고르기 전엔 일부 구획이 숨어 번호가 빈다 |

## 결과
- 새 화면도 **칸과 괘선**으로 짠다. 떠 있는 카드·그림자·둥근 모서리를 새로 들이지 않는다
- 이어지는 칸은 괘선을 겹쳐 붙인다(`[&>*+*]:-mt-px`). 칸 사이에 틈을 두지 않는다
- 색 규칙(ADR-0014/0015)은 바뀌지 않았다
